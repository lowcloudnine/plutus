# Plutus

Plutus is a small PyQt6 desktop application for tracking gold and silver
holdings in a local encrypted SQLite database.

## Features

- Add, edit, delete, and view gold and silver holdings.
- Store data locally in an encrypted SQLite database.
- Show running totals for ounces and total cost.
- Build Linux, Windows, and macOS desktop bundles with PyInstaller.
- Publish documentation with MkDocs Material.
